# Canvas source (reference only)

These `.dc.html` files are the source of the Claude design canvas "CareerVerse — Game Screens". They depend on the canvas runtime (`support.js`, `<x-dc>` templates) and **will not render on their own**. Use them to read exact values (spacing, copy, colours).

For runnable designs use:
- `design/prototype/index.html`: the interactive responsive app (phone + desktop).
- `design/maps/*.html`: pages, question and qualifier maps as standalone pages.
