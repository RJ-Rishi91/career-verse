# Content

- `schema/scenario.schema.json`: draft JSON Schema for authored call scenarios (developer recommendation).
- `scenarios/L1_MARCUS_STATUS_UPDATE.json`: sample Level 1 status-update call with two decisions, branching, a critical-mistake path and two recovery paths. Validates against the schema; all links resolve; all nodes reachable. **Status: draft. Needs insurance subject-matter review before publish.**
- `clients.json`: Level 1 client roster (3 clients) with personas, starting meters, preferences and portrait parameters.
- `rules.config.json`: scoring weights, caps, XP/coins, thresholds, unlocks. **All numbers are placeholders** until playtesting (open decisions 3–6). Server-side only.

Characters, companies and situations are fictional placeholders.
